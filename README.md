# BLADE/SLASH

Prototipo de videojuego 3D en tercera persona, de supervivencia por oleadas, inspirado en *Risk of Rain 2*. Desarrollado como proyecto de prueba para aprender **Godot 4**.

## Sobre el proyecto

Este es un prototipo funcional (no un juego terminado) que implementa el loop central del género: moverte, combatir, sobrevivir oleadas cada vez más difíciles, y progresar recogiendo mejoras.

## Características implementadas

- Movimiento y cámara en tercera persona
- Sistema de disparo a distancia (proyectiles)
- Ataque cuerpo a cuerpo (corte horizontal de área)
- Director de oleadas: enemigos que aparecen en cantidad creciente
- IA de enemigos con persecución (NavigationAgent3D)
- Sistema de vida, daño y muerte (jugador y enemigos)
- Progresión mediante items que suben estadísticas (daño, velocidad, vida)
- Interfaz: barra de vida, contador de oleada, pantalla de Game Over
- Efectos de partículas y menú principal

## Motor y herramientas

- **Godot 4** (GDScript)
